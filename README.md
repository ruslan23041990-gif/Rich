# 🤖 Bybit Trading Bot

## Описание

**Rich** - это автоматизированный трейдинг бот для краткосрочных сделок (скальпинга) на бирже **Bybit**. Бот использует технический анализ (RSI, MACD, Bollinger Bands, EMA) для автоматического открытия и закрытия позиций с целью максимизации прибыли и управления рисками.

### Основные возможности:

✅ **Автоматический анализ рынка** - использует множественные технические индикаторы
✅ **Краткосрочная торговля** - оптимизирован для 5-минутных свечей (скальпинг)
✅ **Управление рисками** - автоматический стоп-лосс и тейк-профит
✅ **Управление депозитом** - расчет оптимального размера позиции
✅ **Уведомления в Telegram** - получайте уведомления о каждой сделке
✅ **Логирование** - полная история всех операций
✅ **Интеграция с API Bybit** - прямое подключение к бирже

TELEGRAM_CHAT_ID=your_chat_id_here

## 🔑 Получение API Ключей Bybit

1. Перейдите на https://www.bybit.com/app/user/api-management
2. Нажмите "Create New Key"
3. Выберите "Personal" тип ключа
4. Установите разрешения:
   - ✅ Read (для получения данных)
   - ✅ Trade (для открытия/закрытия позиций)
5. Скопируйте **API Key** и **Secret Key**
6. Добавьте их в файл `.env`

**⚠️ ВАЖНО:** Никогда не делитесь вашими API ключами! Они дают полный доступ к вашему аккаунту.

## 🎯 Как это работает

### 1. Анализ Рынка

Бот анализирует рынок каждые 5 минут, используя:

- **RSI (Relative Strength Index)**
  - RSI < 30 → Перепроданность (сигнал BUY)
  - RSI > 70 → Перекупленность (сигнал SELL)

- **MACD (Moving Average Convergence Divergence)**
  - MACD пересекает Signal Line снизу → BUY
  - MACD пересекает Signal Line сверху → SELL

- **Bollinger Bands**
  - Цена < Lower Band → BUY
  - Цена > Upper Band → SELL

- **EMA (Exponential Moving Average)**
  - Цена > EMA → Uptrend (BUY)
  - Цена < EMA → Downtrend (SELL)

### 2. Открытие Позиции

Когда бот получает сигнал:
1. Проверяет условия:
   - Количество открытых позиций < MAX_POSITIONS
   - Дневной убыток < MAX_DAILY_LOSS
   - Баланс достаточен
2. Рассчитывает размер позиции на основе баланса (1% риска на сделку)
3. Автоматически устанавливает Stоп-Лосс и Тейк-Профит
4. Открывает позицию
5. Отправляет уведомление в Telegram

### 3. Закрытие Позиции

Бот закрывает позицию при:
- ✅ Достижении Тейк-Профита (+4% прибыли)
- ❌ Достижении Стоп-Лосса (-2% убытка)
- 🛑 Остановке бота (graceful shutdown)

## 📊 Технические Индикаторы

### RSI (Relative Strength Index)
```
Used for: Определение перекупленности/перепроданности
Period: 14 свечей
Overbought: > 70 (сигнал SELL)
Oversold: < 30 (сигнал BUY)
```

### MACD (Moving Average Convergence Divergence)
```
Used for: Определение тренда и импульса
Fast EMA: 12
Slow EMA: 26
Signal Line: 9
```

### Bollinger Bands
```
Used for: Определение уровней сопротивления/поддержки
Period: 20
Standard Deviation: 2
```

### EMA (Exponential Moving Average)
```
Used for: Определение направления тренда
Period: 20
```

## ⚙️ Управление Рисками

### Особенности управления рисками:

1. **Stop Loss & Take Profit**
   - Автоматически устанавливается для каждой позиции
   - Stop Loss: -2% от входной цены
   - Take Profit: +4% от входной цены

2. **Размер Позиции**
   - Рассчитывается автоматически на основе баланса
   - Риск не превышает 1% баланса на сделку

3. **Макс. Позиций**
   - Макс. 3 открытые позиции одновременно
   - Предотвращает избыточную концентрацию риска

4. **Дневной Лимит Убытков**
   - Макс. $500 убытка в день
   - После достижения лимита бот прекращает торговлю

## ⚠️ Риски и Дисклеймер

### Важно:

⚠️ **Торговля на финансовых рынках сопряжена с высокими рисками!**

- Бот использует **плечо (leverage)**, что увеличивает риск потерь
- Вы можете потерять весь свой депозит
- Прошлые результаты не гарантируют будущие результаты
- Начните с **малых сумм** и **тестовой сети (testnet)**
- Не инвестируйте деньги, которые вы не можете позволить себе потерять

### Рекомендации:

1. **Тестируйте сначала на TESTNET:**
   ```bash
   # В .env файле установите:
   BYBIT_TESTNET=True
   ```

2. **Начните с маленьких сумм** ($100-500)

3. **Мониторьте бота** хотя бы в первые дни

4. **Не добавляйте все свои деньги сразу**

5. **Отключайте бота** когда спите (риск гэпов и крешей)

## 🐛 Решение Проблем

### Проблема: "Failed to initialize Bybit API"

**Решение:**
- Проверьте правильность API ключей в `.env`
- Убедитесь, что ключи имеют разрешение на торговлю
- Проверьте интернет соединение

### Проблема: "Insufficient account balance"

**Решение:**
- Пополните баланс на Bybit
- Уменьшите `POSITION_SIZE` в `.env`
- Проверьте что деньги на UNIFIED аккаунте

### Проблема: "No signal" (бот ничего не делает)

**Решение:**
- Это нормально! Бот ждет хороших сигналов
- Проверьте логи: `tail -f logs/trading_bot.log`
- Может потребоваться больше времени для анализа

### Проблема: Бот закрывает все позиции со стоп-лоссом

**Решение:**
- Уменьшите волатильность индикаторов
- Увеличьте `STOP_LOSS_PERCENT`
- Проверьте параметры RSI/MACD
- Возможно, рынок очень волатилен
